# Smart Exam Application 📝

A full-screen desktop-based examination system developed using Python and Tkinter.  
The application is designed to conduct mock tests with section-wise selection in a clean and user-friendly interface.

---

## 🚀 Features
- Full-screen responsive UI
- Section-wise exam selection
- Clean and minimal design
- User-friendly navigation
- Suitable for academic and practice exams

---

## 🛠️ Technologies Used
- Python 3
- Tkinter (GUI Library)

---

## ▶️ How to Run the Project
1. Clone the repository
2. Open terminal inside the project folder
3. Run the command:
   ```bash
   python smartexam.py
